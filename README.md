# JabRef demonstration libraries

This repository contains Bib(La)TeX libraries to demonstrate JabRef's features.

- [`chocolate/Chocolate.bib`](chocolate/Chocolate.bib): papers on chocolate and health, with a [step-by-step guide](chocolate/pdfs/README.md) for attaching PDFs.
- [`intro/intro.bib`](intro/intro.bib): a small selection of works on TeX, LaTeX, BibTeX, and JabRef.
- [`jabref/jabref.bib`](jabref/jabref.bib): JabRef in the media — articles, listings, and research papers discussing or using JabRef, grouped by kind. See [its README](jabref/README.md).
