# JabRef in the media

[`jabref.bib`](jabref.bib) lists articles, reviews, listings, and research papers where JabRef is discussed.
It replaces the former "JabRef in the Media" page of the JabRef wiki.
The sections of that page are the groups of the library; remarks on an entry are in its `comment` field.

Feel free to add something via a pull request.
